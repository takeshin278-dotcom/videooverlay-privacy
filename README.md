# VideoOverlay プライバシーポリシー

最終更新日：2026年10月7日

VideoOverlay は、ユーザーの個人情報を外部サーバーへ収集・送信しません。

## カメラ・マイク

本アプリは、動画撮影および音声録音のためにカメラとマイクを使用します。

撮影した動画および音声は端末内に保存され、開発者または第三者へ送信されません。

## アクセシビリティサービス

本アプリは、音量キーによる録画操作を行うためにアクセシビリティサービスを使用します。

アクセシビリティサービスを利用して、個人情報を収集、保存、外部送信することはありません。

## オーバーレイ表示

本アプリは、他のアプリの上に動画や操作ボタンを表示するためにオーバーレイ権限を使用します。

## データの収集・共有

本アプリは、ユーザーの個人情報を収集または第三者と共有しません。
